# Yojoli Repo Runner

Managed CI runners in your cloud. The first target is on-demand GitHub Actions runners in a customer's AWS account. [Yojoli is our first customer](docs/pilots/yojoli.md).

New to Repo Runner? Start with the [easy-start guide](docs/quick-start.md). For installation and teardown details, use the [advanced operator guide](docs/pilots/operator-guide.md).

Contributors can start with the [implementation plan](docs/plan.md) and [agent instructions](AGENTS.md). The manual smoke workflow is a template for the private pilot repository.

The [AWS sandbox pilot](infra/pilot/README.md) documents the Terraform configuration and local validation steps.
