# Yojoli Repo Runner

Managed CI runners in your cloud. The first target is on-demand GitHub Actions runners in a customer's AWS account. [Yojoli is our first customer](docs/pilots/yojoli.md).

Start with the [implementation plan](docs/plan.md) and [agent instructions](AGENTS.md). The repository currently includes a manually dispatched pilot smoke workflow. It requires a matching runner pool to be provisioned first.
